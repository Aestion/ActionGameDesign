# 动作游戏设计知识图谱

这是一个可持续维护的动作游戏设计知识库。内容以结构化 Markdown 保存，构建后生成不依赖数据库、CDN 或在线服务的静态网站；核心入口是概念星图，辅以搜索、游戏比较矩阵、案例、冲突和来源索引。

## 阅读成品

1. 打开 [`dist/index.html`](dist/index.html)。Windows 下可直接双击，浏览器会以 `file://` 方式运行。
2. 分享给同事时，必须复制整个 `dist/` 目录，不能只复制 `index.html`；31 个图片/GIF 位于 `dist/media/`。
3. 部署到内网时，将整个 `dist/` 目录放入任意静态文件服务器，不需要服务端程序或数据库。

外部来源链接只在读者主动点击时打开。页面加载、搜索、星图、矩阵和媒体浏览都在本地完成。

## 一键更新

环境要求：Windows、Node.js 24（首次使用需在项目目录执行一次 `npm install`）。

双击 `更新知识库.cmd`。脚本会依次加载并校验 `content/`、生成搜索/图谱数据、构建静态页面、复制媒体、验证离线约束，再发布到 `dist/`。

- 成功：命令窗口显示 `知识库已更新`，打开新的 `dist/index.html`。
- 失败：窗口显示错误；现有 `dist/` 不会被失败构建覆盖，上一可用版本仍可阅读。
- `dist-last-good/` 是发布时的上一版备份，不要把它当作当前成品分享。

常用命令：

```powershell
npm run dev        # 生成内容并启动本地开发预览
npm test           # 运行内容、交互、离线和覆盖测试
npm run build      # 生成经过离线校验的正式 dist/
```

## 目录说明

- `content/`：唯一的人工维护知识内容。
- `content/coverage.json`：六篇原资料的段落、案例和媒体覆盖账本。
- `原始资料/`：六篇原始 `.md` 资料及其配套媒体（`动作游戏设计之难_assets/`），作为可追溯来源保留，不直接改名或覆盖。
- `src/`：构建和交互界面代码。
- `dist/`：可交付成品。
- `docs/content-authoring.md`：新增或修改知识节点的完整规范。

## 内容原则

- 保留观点、限定条件、反例、分歧和所有游戏案例，不逐字复制全文。
- 同一维度的冲突并列展示，不裁决唯一正确答案。
- 来源观点、编者解释和编者归纳必须明确分开。
- 新内容必须更新覆盖账本并通过构建；不要直接编辑生成文件 `src/generated/knowledge.ts` 或 `dist/`。
