# docs/ia

动作游戏研究的信息架构与交互样张。

- **`rough-pages/index.html`**：优先看。分页粗稿，每个内容单独一页：发展 / 定义 / 难点 / 观点 / 对比 / 标尺 / 来源。
- **`rough-pages/preview-*.png`**：分页粗稿的首页、对比页、观点页、标尺页截图。
- **`rough-draft.html`**：单页版（旧）。所有内容放在一页，太长，保留作对照。
- **`action-game-reader-ia.md`**：信息架构与内容模型。记录页面职责、实体、对比单元格和录入流程。
- **`interaction-demo.html`**：详细交互示例。包含搜索、抽屉、主题、结构层、单元格编辑、差距视图等完整组件；用于看交互状态，不是内容定稿。
- **`previews/`**：详细交互示例的截图。
- **`demo-src/`**：详细交互示例的源码、构建脚本和 jsdom 冒烟测试。
- **`rough-draft-preview.png`**：单页版首页截图。

两个 HTML 都是单文件、无外部资源请求，可以直接双击打开。内容中的定义、观点、冲突与来源来自当前知识库；发展时间轴的年代与部分对比单元格仍是粗稿，未完成处用 `—` 或“待补”标出。
