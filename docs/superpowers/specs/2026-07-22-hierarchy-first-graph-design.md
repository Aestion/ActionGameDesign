# 星图层级阅读优化设计

## 目标

将概念星图从同时表达层级与横向关系的网络图，改为以层级阅读为主的聚焦视图。用户应能快速确认当前节点位于哪里、下一步可以进入哪些子节点，并在需要时单独查看横向关联。

## 交互模型

- 根节点视图只显示“动作游戏设计”和六大知识域。
- 选中普通节点后，画布只显示其结构父级、当前节点和直接子节点。
- 画布只绘制 `parent_of` 与 `child_of` 结构边，不绘制冲突、对照、相关、案例或来源边。
- 节点使用稳定的三层坐标：父级在上、当前节点居中、子节点在下。节点选择不触发随机或辐射式重排。
- 面包屑提供返回路径；点击父级、子节点或面包屑都会切换当前节点。
- 多父节点最多同时显示两个结构父级，避免隐藏有效归属，也避免父层无限扩张。
- 当前节点没有父级或子节点时，对应层级不显示空占位。

## 横向关联

- 非结构关系移出画布，集中到画布下方的“关联节点”区域。
- 区域默认折叠，仅显示关联总数和展开按钮。
- 展开后按“冲突”“对照”“相关”“案例与应用”分组显示文本按钮，不绘制连线。
- 每个目标节点在同一分组只出现一次；双向编译边不得造成重复。
- 点击关联节点后切换焦点并自动收起关联区域，让用户重新从该节点的层级上下文开始阅读。
- 无横向关联时不显示该区域。

## 视觉与可访问性

- 增大节点尺寸和字号，统一使用紧凑矩形；当前节点使用更强边框和背景，父级与子级使用不同的次级样式。
- 层级边使用低对比度实线，不使用箭头堆叠、虚线和多色图例。
- 删除画布内关系图例和悬浮统计卡；摘要与统计继续由右侧详情面板承担。
- 保留键盘导航：方向键在当前可见节点间移动，Enter 选择，Escape 返回首个父级或根节点。
- 桌面端使用图形层级视图；移动端继续使用现有折叠树，避免在窄屏压缩图形节点。

## 代码边界

- `GraphExplorer.tsx` 提供纯函数构建层级视图模型，负责节点筛选、父子去重、关系分组和固定坐标。
- Cytoscape 只负责渲染结构节点与结构边，不再决定布局或关系优先级。
- 关联列表作为 `GraphExplorer` 内的独立语义区域，通过已有 `onSelect` 回调导航，不引入新的全局状态。
- `App.tsx` 只更新星图说明文字，不改变详情面板和其他研究视图。
- `styles.css` 仅调整星图及关联区域样式。

## 构建入口恢复

当前工作区的 `index.html` 被另一个 XlsxDiffMerge 网站的构建产物覆盖，并引用不存在的资源。实施时将其恢复为本仓库的 Vite 入口，即包含 `#root` 和 `/src/main.tsx` 的版本。未跟踪的 `site.png` 保持不动。

## 测试与验收

- 单元测试验证根视图只含根和六域。
- 单元测试验证普通节点只含最多两个父级、当前节点和直接子节点。
- 单元测试验证画布边全部为结构边，横向边仅进入分组列表且不重复。
- 组件测试验证关联区域默认折叠、展开、跳转后收起。
- 保留并更新键盘、面包屑和移动树测试。
- 运行完整 `npm test` 和 `npm run build`。
- 使用浏览器在桌面与移动视口检查节点不重叠、文字可读、关联列表可操作，并确认控制台无错误。

## 非目标

- 不修改知识内容、关系数据或覆盖账本。
- 不新增关系筛选器、布局模式切换或自由编辑能力。
- 不改变游戏矩阵、案例索引、冲突索引和来源档案。
