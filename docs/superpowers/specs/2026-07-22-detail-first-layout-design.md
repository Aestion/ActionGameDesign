# 详情主导星图与三段详情面板设计

## 目标

将概念星图从主要阅读区域收缩为辅助定位区域，把右侧详情面板扩展为主要信息入口。详情面板不再提供 L1/L2/L3 深度切换，所有选中节点直接展示完整研究内容，并将内容稳定组织为“简述、详细、补充”三段。

## 已确认的产品决策

- 采用“层级优先的宽详情栏”方案。
- 左侧导航保持现有结构和职责。
- 中间星图继续保留父级、当前节点、直接子节点的层级表达，但降低空间占比。
- 右侧详情栏扩展到约 `480–560px`，作为桌面端主阅读区。
- 完全移除 L1/L2/L3 指示器、切换按钮、深度状态和深度切换逻辑。
- 移动端继续隐藏桌面星图并显示 `MobileTree`；详情面板在树下完整展开。

## 详情内容结构

`NodeDetail` 固定渲染三个语义区块，区块内部允许使用轻量小标题，但不再把每项内容设计成同等重量的独立面板。

### 1. 简述

- 节点摘要。
- 知识域和复核状态。
- 关系、案例、冲突计数。

### 2. 详细

- 节点正文和结构化解释。
- 条件与边界标签。
- 相关概念入口。

### 3. 补充

- 案例卡或案例入口。
- 冲突问题、冲突双方及条件。
- 媒体和引用来源。
- 编者综合判断，作为本段末尾的结论区并保留橙色强调。

缺少数据时只显示一句简短空状态，不生成大面积空白容器。已有案例卡、冲突卡、媒体对话框和来源链接继续复用。

## 布局设计

桌面端 `.atlas-layout` 仍为左导航、星图工作区、详情面板三列，但调整列比例，使详情面板成为主要阅读区域。默认目标是左导航约 `220px`，星图区域使用剩余空间中的较小比例，详情面板约 `480–560px`；在 `1180px` 左右的中等桌面宽度下同步收缩，但不允许详情面板挤压到不可读宽度。

星图画布高度从当前的大型展示高度降低到更紧凑的辅助导航高度；节点关系、键盘可访问节点列表、关联节点折叠区和移动树的行为保持不变。

详情面板继续独立纵向滚动。标题、三段结构和结论区必须在宽面板内保持清晰层次；重复卡片只用于案例、冲突等真正的重复项，不增加新的装饰性嵌套卡片。

## 状态与接口

- 从 `AtlasState` 删除 `detailDepth`。
- 从 `AtlasAction` 删除 `set-detail-depth`。
- `App` 不再向 `NodeDetail` 传 `depth` 或 `onDepthChange`。
- `NodeDetail` 只保留实体、数据集和节点跳转回调等必要参数。
- 不修改知识数据模型中的实体 `depth` 字段；该字段仍用于内容和构建校验，但不再驱动右侧面板交互。

## 验证标准

- App 初始状态和 reducer 不再包含详情深度状态。
- 页面中不存在 L1/L2/L3 深度切换按钮和当前深度指示器。
- 任意节点一次渲染出“简述、详细、补充”三个区块。
- L3 原有信息仍完整存在：正文、条件、相关概念、案例、冲突、媒体、引用、综合判断。
- 桌面浏览器检查确认星图缩小、详情栏变宽，文字不重叠且详情区可独立滚动。
- `390x844` 检查确认移动树和详情面板仍可读，桌面星图隐藏。
- `npm test` 和 `npm run build` 通过；构建允许保留既有内容完整性 warning。

## 非目标

- 不修改知识内容、实体的内容深度字段或研究视图数据。
- 不改变上一轮已确认的星图层级模型和关联节点导航逻辑。
- 不引入新的第三方 UI 组件或富文本编辑器。
